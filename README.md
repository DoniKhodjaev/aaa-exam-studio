# AAA Exam Studio

Тренажёр ACCA Advanced Audit & Assurance: 5 полных пробных экзаменов (Section A 50 + 2×Section B 25),
таймер по нормативу ACCA, проверка ответов ИИ через Anthropic API, образцовые ответы, доработка
с перепроверкой, генератор новых вопросов и чек-лист пробелов.

## Деплой на GitHub Pages

1. Создайте репозиторий и запушьте эти файлы в ветку `main`.
2. В репозитории: **Settings → Pages → Source: GitHub Actions**.
3. После пуша workflow соберёт сайт сам — ссылка появится в **Actions** и в Settings → Pages
   (`https://<username>.github.io/<repo>/`).

## Подключение API-ключа

1. Создайте ключ: console.anthropic.com → **API keys** (лучше отдельный ключ для этого сайта).
2. Поставьте на ключ месячный **Spend limit**.
3. Откройте сайт → **Настройки** → вставьте ключ → Сохранить.

Ключ хранится только в localStorage браузера и отправляется только на `api.anthropic.com`
(прямой доступ из браузера включён заголовком `anthropic-dangerous-direct-browser-access`).
В репозиторий и на GitHub ключ не попадает. История попыток и черновики тоже хранятся локально
на устройстве.

## Локальная разработка

```bash
npm install
npm run dev
```

Все 15 встроенных заданий — оригинальные, по формату и силлабусу AAA (INT). Оценка ИИ — ориентир
для тренировки, не официальная оценка ACCA.

## Стандарты

Раздел «Стандарты»: 30 стандартов IFRS и IAS, проверяемых на AAA. По каждому — суть на языке экзамена (The rule), аудиторский угол (Audit angle) и вопросы на проверку. По каждому стандарту также блок «Where companies go wrong» — 136 типичных нарушений с указанием, как каждое искажает отчётность, плюс отдельный список всех нарушений с поиском. Три режима тренировки: тест по стандартам (номера, названия, содержание и поиск нарушенного стандарта — 266 вопросов), тренажёр номеров с вводом вручную и сквозной просмотр нарушений.
