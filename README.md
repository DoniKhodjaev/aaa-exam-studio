# AAA Exam Studio

Тренажёр ACCA Advanced Audit & Assurance: 5 полных пробных экзаменов (Section A 50 + 2×Section B 25),
таймер по нормативу ACCA, проверка ответов ИИ через Anthropic API, образцовые ответы, доработка
с перепроверкой, генератор новых вопросов и чек-лист пробелов.

## Деплой на GitHub Pages

1. Создайте репозиторий и запушьте эти файлы в ветку `main`.
2. В репозитории: **Settings → Pages → Source: GitHub Actions**.
3. После пуша workflow соберёт сайт сам — ссылка появится в **Actions** и в Settings → Pages
   (`https://<username>.github.io/<repo>/`).

## Подключение API-ключа

1. Создайте ключ: console.anthropic.com → **API keys** (лучше отдельный ключ для этого сайта).
2. Поставьте на ключ месячный **Spend limit**.
3. Откройте сайт → **Настройки** → вставьте ключ → Сохранить.

Ключ хранится только в localStorage браузера и отправляется только на `api.anthropic.com`
(прямой доступ из браузера включён заголовком `anthropic-dangerous-direct-browser-access`).
В репозиторий и на GitHub ключ не попадает. История попыток и черновики тоже хранятся локально
на устройстве.

## Локальная разработка

```bash
npm install
npm run dev
```

Все 15 встроенных заданий — оригинальные, по формату и силлабусу AAA (INT). Оценка ИИ — ориентир
для тренировки, не официальная оценка ACCA.

## Стандарты

Раздел «Стандарты»: 70 стандартов — 30 по отчётности (IFRS, IAS, Conceptual Framework) и 40 по аудиту (ISA, ISQM 1 и 2, ISAE 3000, ISRE 2400, ISRS 4400, IESBA Code). По каждому: суть на языке экзамена (The rule), как это спрашивают на AAA (Audit angle / How this is examined) и типичные нарушения — 279 сценариев с указанием эффекта на отчётность или на качество аудита. Тренировка: тест на 576 вопросов с фильтрами по типу (номера, названия, содержание, поиск нарушенного стандарта) и по семейству (IFRS/IAS или ISA), тренажёр номеров с вводом вручную и сквозной просмотр всех нарушений с поиском.

## Consolidation Studio (`consolidation.html`)

Практика для работы консолидатором в холдинге. Три курса уроков (88 уроков, 392 задания):
- **Консолидация по МСФО** — 11 модулей: контроль, гудвил, баланс и ОПиУ группы, внутригрупповые операции,
  ассоциированные и СП, изменение долей, IAS 21, ОДДС, трансформация НСБУ → МСФО, процесс закрытия в холдинге.
- **Excel для финансиста** — для уверенного пользователя: XLOOKUP/INDEX/MATCH, SUMIFS/SUMPRODUCT, динамические массивы,
  даты и чистка текста, сводные таблицы, Power Query, финансовые функции, архитектура и трёхстатейная модель, сценарии, графики.
- **Power BI с нуля** — интерфейс, Power Query и M, модель данных (звезда, связи, календарь), DAX (меры, контекст,
  CALCULATE, анализ времени), визуализация, P&L группы, публикация и RLS.

Плюс 44 пошаговых кейса по консолидации с проверкой каждого шага (ответы вычисляются в коде из данных кейса),
практика формул Excel на 49 задачах (математика и проценты + задачи консолидации) (формула вычисляется на листе движком HyperFormula, можно писать по-русски или по-английски, протягивание проверяет знаки $), справочник функций Excel (русские и английские имена) и DAX, глоссарий RU/EN, ИИ-наставник, разбор ошибок
и генератор новых кейсов. API-ключ общий с AAA.
